# 设备验证清单 — 消息提醒器助手 MVP

> **用途**：本机（开发机）无 Android 设备，无法做端到端验证。代码已编译通过 + 单测全绿，但**真实运行行为必须由你在手机上验证**。按本清单逐项确认。
>
> **前置条件**：一部 Android 8.0+ 手机，已安装微信，开启 USB 调试。

---

## 0. 安装 APK

- [ ] **0.1** 用 USB 连接手机，`adb devices` 能列出设备。
- [ ] **0.2** 安装 debug APK：
  ```
  adb install build\app\outputs\flutter-apk\app-debug.apk
  ```
  （首次安装若被拦截，手机上允许"未知来源"安装。）
- [ ] **0.3** 桌面出现"消息助手"图标，点击能启动 App（看到首页"消息助手"+ 空状态"还没有命中消息，去配置关键词吧"）。

## 1. 权限授予（监听能否工作的前提）

- [ ] **1.1** 进入设置页，"通知监听"状态显示"未开启"。
- [ ] **1.2** 点"去开启"→ 跳转系统"通知使用权"页。
- [ ] **1.3** 在列表中找到"消息助手"，打开开关。
- [ ] **1.4** 返回 App 设置页，"通知监听"状态变为"已开启"。
- [ ] **1.5** 状态栏出现常驻通知"消息监听运行中"（前台服务存活标志）。

## 2. 关键词配置

- [ ] **2.1** 首页空状态点"配置关键词"→ 进入关键词页。
- [ ] **2.2** 点"+"新建：关键词填"南京"，类型"包含"，优先级默认 50，保存。
- [ ] **2.3** 列表出现"南京"项。
- [ ] **2.4** 再新建"到"（包含）、"上海"（精确，优先级 80）。
- [ ] **2.5** 验证编辑/删除功能正常。

## 3. 消息监听与匹配（核心闭环）

- [ ] **3.1** 让别人或用另一账号往你所在的微信群里发："南京到上海，今天发车"。
- [ ] **3.2** 手机收到微信通知后，**消息助手**应在数秒内弹出本地通知：
      标题 = 群名/发送人，正文 = "南京到上海，今天发车（命中：南京、到）"。
- [ ] **3.3** 点开消息助手 App，首页列表出现该条，"南京""到"被高亮（黄色背景）。
- [ ] **3.4** 点列表项 → 进入详情页，显示完整内容、命中词、得分。
- [ ] **3.5** 在群里发一条**不含**任何关键词的消息（如"今天天气不错"）→ 消息助手**不**弹通知、列表**不**新增（验证"未命中不入库"）。

## 4. 点击跳转

- [ ] **4.1** 详情页点"复制并打开微信"。
- [ ] **4.2** 微信被唤起到前台（主界面）。
- [ ] **4.3** 在微信任意输入框粘贴，确认剪贴板里是消息内容。
- [ ] **4.4** 出现 Toast/SnackBar"已复制，已打开微信"。
- [ ] **4.5** （若手机未装微信）按钮提示"微信未安装"。

## 5. 去重

- [ ] **5.1** 同一分钟内，让同一个人在同一群连发两条**完全相同**的消息。
- [ ] **5.2** 消息助手只入库/提醒**一条**（同一分钟窗 + 同发送人 + 同内容 = 视为重复）。
- [ ] **5.3** 跨分钟（隔 61 秒以上）再发同样内容 → 视为新消息，再提醒一次。

## 6. 保活

- [ ] **6.1** 按 Home 键把 App 切后台，等 5 分钟，状态栏"消息监听运行中"通知仍在。
- [ ] **6.2** 在最近任务里把消息助手**划掉**（杀进程）。等 15 分钟内（WorkManager 心跳），前台服务应自动重启（通知重新出现）。
- [ ] **6.3** 重启手机 → 开机自启（BootReceiver）应自动拉起监听服务。
      ⚠️ 注意：小米/华为/OPPO/VIVO 等需在系统"自启动管理"里允许消息助手自启，否则开机/杀后台后无法自启。这是厂商限制，非 App bug。
- [ ] **6.4** 杀进程后微信来消息，验证服务重启后仍能收到提醒。

## 7. 夜间静默

- [ ] **7.1** 设置页打开"夜间静默"，设为当前时间所在的时段（如现在 22 点，设 22-7）。
- [ ] **7.2** 群里发含关键词的消息 → 消息**入库**（列表能看到），但**不弹通知**（无响铃/震动/横幅）。
- [ ] **7.3** 关闭静默时段 → 再次发消息 → 通知恢复。

## 8. 关键词热加载

- [ ] **8.1** 群里发"台州到南通"，此时未命中（假设没配"台州"/"南通"）。
- [ ] **8.2** 在 App 新建关键词"台州"。
- [ ] **8.3** 群里再发"台州到南通" → **立即**命中并提醒（无需重启 App）。

## 9. 历史与设置

- [ ] **9.1** 首页右上角"历史"图标 → 历史页显示所有命中记录，可搜索。
- [ ] **9.2** 详情页"标记已回复"→ 状态更新。
- [ ] **9.3** 设置页"隐私政策"可查看。
- [ ] **9.4** "清空记录"目前为占位（功能开发中）。

## 10. 智能复制 + 快捷话术（v2 新增）

> 说明：微信 8.0.76 屏蔽了 AccessibilityService（见 `docs/wechat-accessibility-finding.md`），全自动进群/@/发送不可行。改为"智能复制"：App 组装好 `@发送人 话术` 文本复制到剪贴板 + 唤起微信，用户手动粘贴发送。

- [ ] **10.1** 详情页底部主按钮显示为"回复"（不再是"复制并打开微信"）。
- [ ] **10.2** 点"回复"→ 弹出底部话术面板，列出预设话术：接单（标"默认"）/已发车/稍后联系/已满。
- [ ] **10.3** 点"接单"→ 剪贴板内容为 `@<发送人> 接单`（如发送人是"王师傅"，则 `@王师傅 接单`）。
- [ ] **10.4** 微信被唤起到前台，SnackBar 提示"已复制，已打开微信，请粘贴发送"。
- [ ] **10.5** 在微信输入框长按粘贴 → 确认内容是 `@<发送人> <话术>`，点发送成功。
- [ ] **10.6** 点话术面板底部"自定义…"→ 输入自定义文本（如"今天3点发车"）→ 复制 `@<发送人> 今天3点发车` + 唤起微信。
- [ ] **10.7** 选完话术后，详情页该消息状态变为"已回复"。
- [ ] **10.8** 设置页有"回复话术管理"区，能看到4条预设话术。
- [ ] **10.9** 点"+ 新建话术"→ 输入"马上到"→ 保存 → 列表新增该项。
- [ ] **10.10** 点某话术的"默认"星标 → 该项变默认，其他取消默认。
- [ ] **10.11** 编辑话术文本 → 保存后列表更新。
- [ ] **10.12** 删除话术 → 确认后从列表移除。

## 已知限制（非 Bug，设计取舍）

| 限制 | 原因 |
|------|------|
| 微信内已读消息抓不到 | NotificationListener 只能拿通知栏消息 |
| 群被设为免打扰 → 无通知 → 抓不到 | 依赖系统通知 |
| 同名群视为同一群 | 通知无稳定群 ID，用群名 hash 作伪 ID |
| 点击只能到微信主界面，不能自动进特定群/@发送人 | 需 AccessibilityService，留下一迭代 |
| iOS 无法在此构建/运行 | 开发机为 Windows，iOS 需 Mac+Xcode |

## 排查

- **收不到任何提醒**：① 确认通知监听已授权（设置页状态）；② 确认微信该群**未免打扰**；③ 确认前台服务通知"消息监听运行中"存在；④ 杀后台过度，检查厂商自启动白名单。
- **提醒了但内容是"未知"或截断**：微信通知格式变更，看 `NotificationParser.kt` 的解析规则是否需调整（纯函数，易改）。
- **点击通知没跳详情页**：检查 bootstrap 是否成功初始化（看 adb logcat 的 flutter 日志）。
